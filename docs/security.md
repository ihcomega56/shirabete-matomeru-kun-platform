# セキュリティ設計と本番化チェックリスト

この文書は本番化に必要な確認事項です。初期Bicepテンプレートがすべてを自動設定済みという意味ではありません。

## 信頼境界

- Browserは信頼しない。すべての入力、パラメーター、外部URL、アップロード内容をBackendで検証する。
- モデル、MCPツール、検索結果、保存済みレポートは信頼境界を越えてくるデータとして扱う。プロンプトインジェクションを命令として実行しない。
- 取得したWebコンテンツは質問に答えるための資料に限定し、任意の操作・コード実行・シークレットアクセスを許さない。
- Markdown/HTMLはユーザー入力・モデル出力由来。危険なHTML・スクリプト・イベント属性・`javascript:`リンクを許可しない。
- MCPは許可されたサーバーと読み取り操作に限定し、利用するツール名・スコープ・タイムアウトを明示する。

## 認証・認可・資格情報

- ユーザー認証はMicrosoft Entra IDを前提とし、API側でもトークンの署名、issuer、audience、期限を検証する。CORSは認証の代わりではない。
- App ServiceのManaged Identityを有効にし、Blob、Search、Key Vault、Foundryへ必要最小限のデータプレーン権限だけ付与する。
- Foundry側でAPIのIDを認可する。Search/StorageのアカウントキーやFoundryのAPIキーをFrontend、Git、設定ファイル、ログへ置かない。
- シークレットが不可避な場合はKey Vaultに保存し、参照権限・ローテーション・監査を設定する。
- 本番モードでローカル調査プロバイダーへ暗黙フォールバックしない。実接続の失敗を正常回答として隠さない。

## ネットワーク・データ保護

- 本番ではApp Serviceの受信経路を認証済みの入口に限定し、WAF/API保護、TLS、必要なIP/ネットワーク制限を設計する。
- Storage、Search、Key Vault、FoundryのPrivate EndpointとPrivate DNS、App Service VNet統合、アウトバウンド制限を環境要件に合わせて評価する。
- 初期Bicepは公開ネットワーク経由の開発土台であり、Private Endpointや閉域接続を構築しない。本番採用前にネットワーク設計と疎通確認が必要。
- Storageのコンテナーは非公開にする。ライフサイクル管理、冗長性、バックアップ/復旧、暗号化、保持・削除ポリシーを決める。
- レポートに含まれる質問・会話・出典が機微情報となる可能性を考慮し、収集データの最小化、暗号化、保管場所、保持期間、削除方法を定義する。
- 検索結果の認可を実装する。すべての利用者がすべてのレポートを見てよいとは限らない。テナント／ユーザー境界が必要ならインデックス設計時にフィルター属性を含める。

## agent / 検索の安全策

- agentに与える操作権限を読み取り中心にし、外部ページの取得先・ドメイン・応答サイズ・リダイレクト・タイムアウトを制限する。
- SSRF対策として、利用者指定URLを無制限にBackendから取得しない。MCP URLは管理者が設定した許可リストを用いる。
- 引用元を回答本文の主張に対応づけ、URL、タイトル、確認日時を保存する。出典がない主張を公式情報と表示しない。
- Searchインデックスに登録する前に文書サイズ・型・文字コードを検証し、削除や再生成時のインデックス一貫性を確認する。
- agentの最大実行時間、トークン、同時実行数、ユーザー別レート、予算アラートを設ける。

## 本番化前の確認

- [ ] Entra ID認証とアプリ/API双方の認可・ロールを検証
- [ ] Managed Identityと最小権限RBACを検証。鍵ベース認証を無効化できるか確認
- [ ] Private Endpoint/DNS/VNet、egress制御、WAF/API制限を設計・試験
- [ ] Foundry agent、モデル、MCPの許可ツール・データ保持・リージョン・クォータを確認
- [ ] Markdown/HTMLのXSS、プロンプトインジェクション、SSRF、認可越境、レート制限を試験
- [ ] バックアップ、復元、保持期間、削除、監査証跡、データ所在地を決定
- [ ] 障害時のタイムアウト、再試行、重複登録、Search再構築を試験
- [ ] Azure Monitorのアラート、当番通知、運用手順とコスト上限を設定
- [ ] SRE Agentの実環境での利用可否と必要権限を確認。変更操作は明示承認に限定
